# 🎮 Chiikawa vs Usagi

A simple 2-player fighting game developed for a Computer Graphics project using **C++** in **Code::Blocks**.

Built with:
- C++
- Code::Blocks

---

## 🎮 Controls

| Action | Chiikawa (Player 1) | Usagi (Player 2) |
|--------|---------------------|------------------|
| Move Up | W | ↑ |
| Move Left | A | ← |
| Move Down | S | ↓ |
| Move Right | D | → |
| Attack | X | Enter |
