# 🎮 Chiikawa vs Usagi

A simple 2-player fighting game developed for a Computer Graphics project using **C++** in **Code::Blocks**.

Built with:
- C++
- Code::Blocks

---

## 🎮 Controls

### Player 1 - Chiikawa

| Key | Action |
|------|--------|
| W | Move Up |
| A | Move Left |
| S | Move Down |
| D | Move Right |
| X | Attack |

### Player 2 - Usagi

| Key | Action |
|------|--------|
| ↑ | Move Up |
| ← | Move Left |
| ↓ | Move Down |
| → | Move Right |
| Enter | Attack |
